# 渲染与交付

生成实际图形时，阅读当前输出方式的部分和末尾的检查规则。先找环境已有的渲染器和项目脚本，使用其实际支持的语法。

## Mermaid

- 用稳定的简短 ID 和独立显示标签；需要时用引号保护中文、括号及标点。保留一份可编辑源，文件交付时用 `.mmd` 或 Markdown 中的 `mermaid` 代码块。
- 自动布局以读者追踪路径为准。流程以主路径和分支安排方向；过宽时改方向或拆分，过高时压缩冗余节点、注释和间距。不能靠持续缩小文字容纳内容。
- 子图内部方向、跨边界边和复杂状态语法以实际渲染效果为准；若特定语法不可用，可用普通 flowchart 表达相同含义并保留类型/边界标签。
- 若已有 Mermaid CLI，可使用 `mmdc -i input.mmd -o preview.svg`；图像检查使用现有 SVG 查看器，或渲染 PNG。CLI/布局插件未安装不能称为已验证，专用 skill 本身也不是渲染器。
- 需要配置主题、布局或 C4 特定语法时，查询所用版本的本地文档或官方文档；不要假设某个客户端支持全部 Mermaid 特性。

## SVG / HTML

- 简单独立图可直接交付 SVG；需要页面承载时用单文件 HTML，内联必要样式、脚本与图形。优先使用本地资源；要求离线时核对字体、图片及绘图库依赖均可离线使用。
- 使用现成渲染器时按其接口提供内容；自定义 HTML/SVG 时只实现当前所需的布局与交互。样式遵循 [主文件](../SKILL.md) 中的优先级。
- 先按内容确定布局，再决定画布。文档图采用内容适配的宽高；幻灯片或印刷遵循指定尺寸。关键字在实际阅读尺寸可辨，中文标签在合理词组边界换行。
- 线条避开非端点节点及边界标题。不同连线使用可区分的接入点；交叉处用间隙或桥接标示，标签有充分留白。节点遮住线路不等于修好了穿线。
- 颜色承载稳定含义或少量重点；文本/线型也表达关键差别。主流程、例外、外部依赖和未知的视觉区别由任务决定，避免给普通内容加装饰性卡片。
- 每个 SVG 使用独立的 ID 前缀，包括 markers、clipPaths、标题和描述；`role="img"` 与 `aria-labelledby` 指向简短标题和内容说明。
- 优先在窄屏保持合理字号。无法重排的复杂图在局部容器横向滚动，页面正文仍可正常阅读；不要缩成一张不可读缩略图或让整个页面溢出。
- 单独导出 SVG 时带上其实际使用的样式、defs 和字体回退，避免离开 HTML 后颜色、箭头或文字消失。

## 数据图与交互

- 科学、精确数值或出版用途，优先已有绘图库，保存数据及生成代码；不要手工估计坐标冒充数据绘图。
- 交互若能帮助比较方案、切换层级或观察变化，可使用环境支持的交互载体。保证默认视图有完整含义；纯静态需求不引入运行服务。
- 动画保留完整静态/打印结果，尊重减少动态效果设置。仅靠动画出现的约束也应能在静态视图中找到。

## 检查实际交付版本

语义、语法、视觉检查回答不同问题：

| 检查 | 可以证明 | 不能证明 |
|---|---|---|
| 对照原文核对 | 已知事实、方向、约束得到保留 | 字体大小、遮挡、读图难度 |
| 解析/结构检查 | 工具接受语法、引用可解析 | 图一定正确或好读 |
| 渲染并查看 | 所看版本的可见排版与阅读尺度 | 隐藏分支的业务规则都正确 |

查看最终图的实际阅读尺寸，检查文字截断、线与标签遮挡、图例和数据比例；行为图追踪正常及重要异常/返回路径。多视图检查各自画面及对应关系；HTML 还检查整页组织，宣称窄屏可读前查看窄屏。

使用自动几何检查时，确认它支持当前 SVG 的坐标空间、CSS marker 和 transform。识别数为零或覆盖不全只能算部分检查，不能替代看图。

发现问题后定点修改并重渲染。已清晰即可交付；仅当仍有具体问题时继续迭代。工具持续失败时尝试可用的等价工具或更简单的表达，无法查看的版本如实标为未做视觉检查。

交付文件链接与可编辑源；PNG 是预览而非唯一源文件。渲染状态和剩余限制放在交付说明，图解正文面向读者。
