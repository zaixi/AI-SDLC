```text
encode_runs(items)
  if items is empty
    return []
  current ← items[0]
  count ← 1
  for each next item
    if next == current
      count ← count + 1
    else
      emit (current, count)
      current ← next
      count ← 1

```

以 `['a','a','b','a']` 为例：

```text
encode_runs
  start run 'a'
    'a' == 'a'  → count 2
    'b' != 'a'  → emit ('a', 2)，另开 'b'
    'a' != 'b'  → emit ('b', 1)，另开 'a'

```

结果是 `[('a', 2), ('b', 1), ('a', 1)]`。空列表没有段，直接返回 `[]`。

```python
def encode_runs(items):
    if not items:
        return []
    runs = []
    current = items[0]
    count = 1
    for item in items[1:]:
        if item == current:
            count += 1
        else:
            runs.append((current, count))
            current = item
            count = 1
    runs.append((current, count))
    return runs
```
