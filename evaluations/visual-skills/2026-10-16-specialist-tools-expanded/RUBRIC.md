# 评审标准（生成前冻结）

V01：14 个内部单元与外部邮件服务区分；原题列出的读写和调用关系、先后约束在相关视图中可找到；OCR 失败需人工重排且入口未知，索引失败只重试索引并保留文本，邮件失败不改变已完成状态且只重试邮件。不得补充协议、消息队列、部署或未知调度。先看全貌，再能定位失败影响；交付可离线浏览的 HTML。

V02：东站、西站各自采集器、网关、缓冲库，共六个独立站内实例，中心汇总服务、归档库；站内读数与缓冲读写正确；两站分别上送，中心分别下发补传；汇总服务写归档库。未决技术不得补充。交付 SVG 和 PNG，适合中文联调文档。

首先检查语义与交付，再看读者是否能找到重点、箭头与标签是否可读。装饰和轻微几何偏差不作为缺陷，除非实际妨碍理解。不要求某个固定图种、视图数、样式。记录生成时间、输入/输出 token、工具修复成本，但不将代码量当质量。非盲评，每题每组一次，不宣称稳定胜率。

V03：材料退回回到采购检查；5000 元边界归主管单审；大额主管通过后才到财务；拒绝终止原申请；全通过后下单、收货确认。流程清楚，避免用复杂展示压过简单问题。

V04：完成率 98%、90%、97%；只有 C 同时满足两门槛；A 费用超限、B 完成率不足。工时 80/20/35 与费用 8000/3000/4500 的单位清楚；可选单位成本约 8.16/3.33/4.64 元。单次试验限制保留，不能综合评分或保证未来效果。
