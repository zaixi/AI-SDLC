# Frozen review criteria

Five existing cases, two conditions, one attempt each. Fresh upstream and revised runs; historical results are context only. No no-skill baseline. Review is not blind.

Primary: preserve required behavior, deliver the requested artifact, retain useful proactive discovery, and converge to a justified recommendation. Evaluate discoveries by relevance and their effect on the decision, not search counts. Distinguish verified capability from assumptions and proposed checks. Assess final integration against the task, not receipt completeness.

R01/R02: rerun prior independent behavior checks in isolated disposable workspaces; inspect reuse and unnecessary changes. R03: verify proposed link coverage and cache behavior against primary sources. A01: distinguish current code paths from legacy code and investigate credible adoption/adapter alternatives. A02: check single-evaluation download, hashes/provenance, publication scope, and migration of currently unpublished results. No publishing or candidate installation for design cases.

Record completion, assumptions, key defects, research breadth/depth, repeated research/delegation, time, model requests, usage including children/compaction, and output length. Separate network failures and budget stops from quality. Do not change the candidate or rerun formal cases after observing results.
